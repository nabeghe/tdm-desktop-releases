# TDM Desktop

**TDM Desktop** — A powerful Telegram download manager that lets you save various types of content from Telegram.

## Features

* Download protected/restricted content from channels, groups, and bots, including protected media
* Download self-destructing or time-limited media
* Download Telegram Stories
* Download profile photos (including high-resolution versions)
* Copy text from protected messages
* View messages without marking them as read (Ghost Mode)

Take full control of your Telegram content with a fast, modern, and powerful desktop experience.

## How to Use

Using TDM Desktop is simple.

### Logging In

1. Download the application from the [GitHub Releases section](https://github.com/nabeghe/tdm-desktop-releases/releases).
2. Extract the downloaded archive to any location.
3. Run `TDM.exe`.
4. Click **Start Downloading**.
5. In the **API Settings** section, enter your **API ID** and **API Hash**. You can obtain them from [my.telegram.org](https://my.telegram.org). More information is provided in the next section.
6. Click **Save Settings**.
7. Enter your phone number, including the country code.
8. Click **Continue**.
9. Enter the verification code sent to your Telegram account and continue.
10. If two-step verification is enabled, enter your password as well.
11. You will then be taken to the main application screen.

### API ID & API Hash

Telegram clients require an API ID and API Hash to connect to Telegram servers.

For privacy and transparency reasons, TDM requires users to provide their own API credentials.

You can easily create and obtain your API ID and API Hash by visiting [my.telegram.org](https://my.telegram.org).

### Downloading

The interface is similar to Telegram Desktop, making it easy to navigate and use.

On the left side, your chat list is displayed. Select any chat to view its messages.

Messages are displayed in a simplified format. Items containing downloadable content include a **Download** button. Clicking it adds the file to the download queue on the right side and starts the download automatically.

You can also click a profile picture at the top of the window to view available stories. A dedicated button is provided for downloading profile photos as well.

Alternatively, you can paste a direct link to a Telegram message or story into the download panel to download it directly.

**Note:** Media files are currently displayed as standard items within the message list. Future updates may introduce additional improvements and enhancements.
